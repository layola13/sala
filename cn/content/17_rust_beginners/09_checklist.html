学习清单

这是本章自己的学习清单，照本章各页写成。（本章所据的草稿里有一份清单，只写到第 3 项就断了；下面是补完的版本。）请主动地用它：每一项都先写出程序，在运行之前先预测它的输出——或者它的报错——然后再编译。预测错了，才是学到了。

基础

  • ☐ 写一个程序：两个 let 绑定，用 += 改其中一个，打印两个——全程不写 mut。
  • ☐ 写一个带显式 return 的 add 函数，从 main 调用它，并让 main 的退出码可见。
  • ☐ 定义一个结构体，用结构体字面量构造它，打印其中一个字段。
  • ☐ 用 format(...) 构造一个 String，并能说清为什么不用 String::from(...)。

所有权

  • ☐ 把一个带 String 字段的结构体按值传入函数，并解释调用方的绑定发生了什么。
  • ☐ 故意在移动之后使用一个值；读 UseAfterMove 诊断，并指出它报告的标识符。
  • ☐ 在 &i32 上写 read 与 modify，并解释为什么不需要 &mut——以及谁判定 Locked_Read 与 Locked_Mut。
  • ☐ 解释为什么在 SLA 里把读者函数改成写者不会牵动它的调用方，而在 Rust 里会。

Copy、Clone 与 Derive

  • ☐ 给一个点结构体 derive copy, eq, ord, hash, debug；在拷贝赋值之后、以及按值调用之后继续使用源值。
  • ☐ Derive clone，用 .clone() 产生一个独立的值。
  • ☐ 给带 String 字段的结构体加 @derive(copy) 并赋值；在编译之前先说清：之后读源值时检查器会说什么。
  • ☐ 说清泛型结构体限制：到底什么失败、报什么错、在哪些构造形式下测过。

枚举、Trait 与泛型

  • ☐ 定义一个带载荷变体的枚举，匹配它的每一个分支。
  • ☐ 为一个结构体实现一个 trait，并用两种方式调用方法：点调用与 Trait::method(&x)。
  • ☐ 写 max<T: PartialOrd> 并用裸名调用它；解释类型参数从哪里来。
  • ☐ 解释为什么以你自己的 trait 为约束的泛型自由函数目前还不能被调用，以及哪两种可用模式可以替代它。

错误、闭包与宏

  • ☐ 从一个函数返回 Result<i32, String> 并匹配两个分支；错误用 format(...) 构造。
  • ☐ 返回一个 Option，匹配 Some 与 None。
  • ☐ 写一个捕获周围绑定的闭包并调用它。
  • ☐ 写一个带最前输出参数的类型化宏，像函数一样调用它；用一句话对比它与 macro_rules!。

并发

  • ☐ 在 rendezvous 通道上启动一个 go 工作者，完成一次请求/响应往返，并用 sa_task_join 汇合它。
  • ☐ 在 thread::spawn 下跑 50 轮双通道乒乓，每次接收都检查 closed 标志。
  • ☐ 用四个工作者搭一个 Arc<Mutex<i32>> 计数器，恰好落到 1000。
  • ☐ 说清 RwLock 的保留意见：期望的终值是多少，更长的实测系列实际显示了什么。

模块、异步与工程

  • ☐ 把一个 helper 拆到自己的文件里、标 pub fn，再用相对路径 @import 拉进来。
  • ☐ 写一个 async fn，在它里面 await 另一个异步调用，并在 main 里 await 它的结果。
  • ☐ 用一段话描述编译路线（检查 → SA 文本 → 本机）与 Referee 在其中的角色。
  • ☐ 说清数据库与网络支持住在哪里，以及本章为什么不为这两者印代码。

本页要点

  • 本清单每一项都对应本章验证过程中真正编译、运行或被拒绝过的一个程序或一条诊断。
  • 先预测再运行：输出——或者确切的诊断——就是检验标准。
