枚举、Trait 与泛型

枚举与 match

带载荷变体的枚举与穷尽 match 与 Rust 程序员的预期一致。注意已验证形态里的表面细节：match 分支取块，语句级 match 以分号收尾。

带 payload 的变体与穷尽 match 正如 Rust 程序员所料。注意已验证形态的表面细节：match 分支用块，语句级 match 以分号结束。下面两边都已编译运行，都输出 ready、running、error 42。

// Rust
enum Status { Ready, Running, Failed(i32) }

fn describe(status: Status) {
    match status {
        Status::Ready => println!("ready"),
        Status::Running => println!("running"),
        Status::Failed(code) => println!("error {}", code),
    }
}

fn main() {
    describe(Status::Ready);
    describe(Status::Running);
    describe(Status::Failed(42));
}
// output: ready / running / error 42
@import "sa_std/io/print.sai"
@import "sa_std/fmt.sai"

    Ready,
    Running,
    Failed(i32),
}

fn describe(status: Status) -> void {
    match status {
        Status::Ready => { println("ready"); },
        Status::Running => { println("running"); },
        Status::Failed(code) => { println("error {}", code); },
    };
}

fn main() -> i32 {
    describe(Status::Ready);
    describe(Status::Running);

Trait 与 impl

Trait 声明、impl Trait for Type 与 &self 接收者都与 Rust 同形。两种调用形式都能分发——点调用与全限定调用：

Trait 声明、impl Trait for Type 与 &self 接收者都与 Rust 对应；点调用与全限定调用两种形式都能派发。下面的 Rust 对应程序已编译运行，输出 42 42，与 SLA 程序完全一致。

// Rust
trait Score { fn score(&self) -> i32; }

struct Item { value: i32 }

impl Score for Item {
    fn score(&self) -> i32 { self.value + 10 }
}

fn main() {
    let item = Item { value: 32 };
    println!("{} {}", item.score(), Score::score(&item));
}
// output: 42 42
@import "sa_std/io/print.sai"
@import "sa_std/fmt.sai"

trait Score {
    fn score(&self) -> i32;
}

struct Item {
    value: i32,
}

impl Score for Item {
    fn score(&self) -> i32 {
        return self.value + 10;
    }
}

fn main() -> i32 {
    let item = Item { value: 32 };
    println("{}", item.score());
    println("{}", Score::score(&item));
    return 0;
}

实测输出：先 42，后 42——item.score() 与 Score::score(&item) 到达同一个实现。第二个 trait，over 一个 f64 计算：

第二个 trait 做 f64 计算，Rust 写法相同；两边都已编译运行，都输出 78.53975 量级的结果：

// Rust
trait Area { fn area(&self) -> f64; }

struct Circle { radius: f64 }

impl Area for Circle {
    fn area(&self) -> f64 { 3.14159 * self.radius * self.radius }
}

fn main() {
    let c = Circle { radius: 5.0 };
    let a = c.area();
    println!("{}", a);
    assert!(a > 78.0 && a < 79.0);
}
// output: 78.53975
@import "sa_std/io/print.sai"
@import "sa_std/fmt.sai"

trait Area {
    fn area(&self) -> f64;
}

struct Circle {
    radius: f64,
}

impl Area for Circle {

带内建约束的泛型函数

以内建 trait 为约束的泛型函数，用裸名定义与调用；类型参数由实参推断，与 Rust 相同：

受内建 trait 约束的泛型函数按名字调用，类型参数由实参推断，和 Rust 一样。Rust 对应程序实测输出 20 3.5；SLA 程序输出同样的整数，浮点以固定精度呈现（3.5000000000）：

// Rust
fn max<T: PartialOrd>(a: T, b: T) -> T { if a > b { a } else { b } }

fn main() { println!("{} {}", max(10, 20), max(3.5, 1.5)); }
// output: 20 3.5
@import "sa_std/io/print.sai"
@import "sa_std/fmt.sai"

fn max<T: PartialOrd>(a: T, b: T) -> T {
    if a > b {
        return a;
    } else {
        return b;
    }
}

fn main() -> i32 {
    println("{} {}", max(10, 20), max(3.5, 1.5));
    return 0;
}

实测输出：20 3.5000000000，退出码 0。没有 turbofish：max::<i32>(10, 20) 式的显式类型实参在 SLA 里是解析错误——推断是唯一的路，这正是下面的调用形式问题要紧的原因。

限制以用户定义 trait 为约束的泛型自由函数目前还不能被调用。下面的定义被接受，但调用被拒绝：
@import "sa_std/io/print.sai"
@import "sa_std/fmt.sai"

trait Score {
    fn score(&self) -> i32;
}

struct Item {
    value: i32,
}

impl Score for Item {
    fn score(&self) -> i32 {
        return self.value + 10;
    }
}

fn calculate<T: Score>(value: &T) -> i32 {
    return value.score();
}

fn main() -> i32 {
    let item = Item { value: 32 };
    println("{}", calculate(&item));
    return 0;
}
Type Check Error: failed to verify types: Undefined call: calculate (error.UndefinedVariable)

第 4 轮验证（2026-11-20）试了所有想得到的调用形式：裸名 + 借用实参、裸名 + 按值实参；去掉约束；先把实参绑到具体类型的局部变量；给结果绑定显式 i32 标注；以及 trait 限定形式 Score::calculate(&item)——它被当作 trait 方法查找解析，并以另一种诊断被拒绝（Type Item does not implement trait method Score::calculate）。全部失败。在这个缺口补上之前，可用的模式是上面已验证的两种：给泛型函数用内建 trait 作约束（PartialOrd），或跳过泛型包装、直接调用 trait 方法——点调用与限定调用今天都能分发。

本页要点

  • 载荷枚举与 match 与 Rust 同形；语句级 match 以分号收尾。
  • Trait 方法可经点调用与限定调用 Trait::method(&x) 两种形式分发。
  • 以内建 trait（如 PartialOrd）为约束的泛型函数用裸名调用、靠推断定型；没有 turbofish 语法。
  • 以用户定义 trait 为约束的泛型自由函数目前还不能被调用（Undefined call），所有已测调用形式都失败——改为直接调用 trait 方法。
