模块与完整覆盖矩阵

import ↔ @import

psa 的 import 对程序自有模块已支持：驱动把整程序 .psa 文件间的 import / from ... import 合并；没有同名本地文件时，import json 绑定 psa_std 库模块（普查，批 D6；标准库的 from-import 在 v1 响亮拒绝）。SLA 的 @import 是对所命名文件的编译期合并——标准库（"sa_std/..."）与程序自有的 .sla 文件用同一种形式，本章每段程序导入标准库时用的都是它。下面这一对，两边各是两个文件。

psaSLA
# mathx.psa
def triple(x):
    return x * 3

# main.psa
from mathx import triple

print(triple(14))  # 42
 
// helper.sla
fn triple(x: i32) -> i32 {
    return x * 3;
}

// main.sla
@import "sa_std/io/print.sai"
@import "sa_std/fmt.sai"
@import "helper.sla"

fn main() -> i32 {
    println("{}", triple(14));
    return 0;
}

实测输出（SLA）：42，退出码 0。

完整矩阵

本章覆盖的每个基础语法点，附 psa 侧普查状态（2026-11-25，2026-11-26 更新；与普查不一致处以任务 171 的条目注明）与 SLA 对应形态。psa 侧「支持」指普查口径已实现且端到端验过；SLA 列写的是本章实际使用——且实际编译验证过——的形态。

没有独立页面的 psa 已登记缺口

  • 海象运算符 :=——前端缺口（普查）。
  • 字节串 b"" 与原始串 r""——前端缺口（普查）。
  • is / is not——普查时是缺口（v1 无身份语义）；已由任务 171-B 实现（身份 = 标签 + 载荷相等），待集成。
  • 任意精度整数——缺口：psa 整数是 i64，溢出响亮失败；bigint 基底项其后已落入 SLA 标准库（S4），但尚未接进 psa 的整数。
  • while/else 与 for/else——前端缺口（普查）。

本章要点

  • psa 与 SLA 在语句层面相遇：几乎每个基础 Python 构造都有直接的 SLA 形态，本章逐对给出完整可运行的程序。
  • 真正的差异是成体系的，不是零散的：动态 vs 静态类型、异常 vs Result/panic、None vs Option，以及 psa 独有的语法糖（切片、推导式、f-string）对 SLA 的显式循环与占位符格式化。
  • 本章每段 SLA 程序都先在所标注的工具链上编译运行、才写进文档；这里点名的每条 psa 限制都可溯到语法普查或编号任务（171-A、171-B），不凭印象。
