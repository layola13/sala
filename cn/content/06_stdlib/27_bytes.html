bytes.sla：字节序列（sla_std）

sla_std 里的纯 SLA 字节序列类型（源码 sla_std/bytes.sla，位于 sa_plugin_sla，并逐字节镜像到 layola13/sla）。它在 SLA 层给出 CPython bytes 的语义： 按惯例不可变的 0–255 字节值序列，带切片、查找、比较、hex / base64 转换与 CPython 形状的 repr。类型本体只有一个 struct：

struct Bytes {
    data: Vec<u8>,
}

值语义。SLA 没有 &mut，所以每个“修改型” 操作都收 &Bytes 并返回一个全新的 Bytes， 参数本身永不被改动。唯一例外是 psa 载体原语 __psa_bytes_set_h（见下），它为 psa 运行时而存在， 不属于通用 API 面。

刻意不提供 bytes_to_str。SLA 有 String.as_bytes()，但没有由字节构造 String 的构造器， 所以在 CPython 里会产生文本的转换（hex()、base64 编码、 repr()）在这里返回装着 ASCII 载荷的 Bytes。 把 Bytes 桥接到字符串值是 psa 胶水层的事，不是本模块的事。

例 1：构造、拼接、查找（可运行程序）

@import "sa_std/io/print.sai"
@import "sa_std/fmt.sai"
@import "sla_std/bytes.sla"

fn main() -> i32 {
    let s1 = format("hello");
    let b = bytes_from_str(&s1);
    let s2 = format(" world");
    let w = bytes_from_str(&s2);
    let c = bytes_concat(&b, &w);
    let s3 = format("world");
    let ndl = bytes_from_str(&s3);
    println("len={}", bytes_len(&c));
    println("first={}", (bytes_get(&c, 0) as i64));
    println("last={}", (bytes_get(&c, -1) as i64));
    println("cmp={}", bytes_cmp(&b, &c));
    println("find={}", bytes_find(&c, &ndl));
    return 0;
}

例 2：值语义与切片

@import "sla_std/bytes.sla"

@test "doc value semantics"() {
    let s = format("abc");
    let b = bytes_from_str(&s);
    let r = bytes_set(&b, 0, 65u8);
    if (bytes_get(&r, 0) as i64) != 65 { panic(1); };
    if (bytes_get(&b, 0) as i64) != 97 { panic(2); };
}

@test "doc slice reverse"() {
    let s = format("0123456789");
    let b = bytes_from_str(&s);
    let e = format("987654321");
    let eb = bytes_from_str(&e);
    let r = bytes_slice(&b, 9, 0, -1);
    if !bytes_eq(&r, &eb) { panic(3); };
}

bytes_set 后 b 仍是 "abc"，返回的是 "Abc"；"0123456789" 以界 (9, 0, -1) 反向切片得 "987654321"——终止界不含，与 CPython 一致。

例 3：hex 往返与越界 panic

@import "sla_std/bytes.sla"

@test "doc hex roundtrip"() {
    let v: Vec<u8> = Vec::new();
    v.push(222u8);
    v.push(173u8);
    v.push(190u8);
    v.push(239u8);
    let b = bytes_from_vec(&v);
    let e = format("deadbeef");
    let eb = bytes_from_str(&e);
    let h = bytes_to_hex(&b);
    if !bytes_eq(&h, &eb) { panic(4); };
    let r = bytes_from_hex(&e);
    if !bytes_eq(&r, &b) { panic(5); };
}

@test should_panic "doc get out of range"() {
    let s = format("abc");
    let b = bytes_from_str(&s);
    let g = bytes_get(&b, 3);
}

panic 码（sla_std 码段）

码条件
9010索引越界（bytes_get / bytes_set）
9011bytes_from_hex：数字个数为奇数、非 hex 数字、或字节对内出现空白
9012bytes_from_b64：坏字符、坏填充或坏长度
9013bytes_slice：step 为零
注意psa 运行时的动态 bytes （tag 15，载荷为 Box<Vec<u8>>）是同一定案的 psa 侧： 两侧约定了相同的载荷形状与载体指针惯用法，所以 psa 胶水可以拆开载体指针， 在 tag-15 值与本 Bytes 类型之间搬运。
