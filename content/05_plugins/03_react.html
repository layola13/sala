react — React Compatibility Layer on SAX

Zig 0.17This plugin is built with Zig 0.17: the 0.17 branch builds with Zig 0.17 and passes the Zig unit tests; the old 0.14.1 branch is kept unchanged.

sa_plugin_react accepts .sax component files, normalizes React DOM-style tags, attributes, and event names, and then produces a browser artifact package of the same shape as SAX's. It is built on the existing SAX lowering pipeline; it is a compatibility layer, not a full reimplementation of React Fiber.

Basic facts

  • Capability segment: react; no plugin dependencies (mui depends on this plugin, not the other way around).
  • Commands: sa react check, sa react build, sa react dev, sa react new.
  • Artifacts: app.wasm, airlock.js, index.html, app.sa (same as SAX).

Enabling and composition

# 在 sa_plugin_react 目录内
SA_PLUGIN_DEV=1 SA_PLUGINS_PATH=$PWD/zig-out/lib/libreact.so \
  sa react build demos/react_counter.sax --out-dir /tmp/react-counter

# 用 --include / -I 组合多个组件源文件（可重复）
SA_PLUGIN_DEV=1 SA_PLUGINS_PATH=$PWD/zig-out/lib/libreact.so \
  sa react check app.sax --include lib/components.sax

An include is first resolved relative to the root .sax; if not found, it searches in turn SA_REACT_INCLUDE_PATH, the share directory inferred from SA_PLUGINS_PATH, installed plugins' $SA_PLUGINS_HOME/installed/<plugin>/current/share, and so on. This lets SAX assets installed by other plugins (such as mui/material.sax) be consumed without a dedicated expander.

Main capabilities provided (summary)

  • React DOM attribute aliases (className, htmlFor, tabIndex, etc.) and event aliases (including the *Capture variants).
  • React-style event references onClick={increment}, while keeping the SAX style onClick={^increment}; supports opt-in Sla handlers fn handler() { ... }.
  • A synthetic event bridge: target/currentTarget, keyboard, pointer, wheel, touch, clipboard, drag-and-drop, modifier keys, preventDefault / stopPropagation.
  • Capitalized-tag user component composition, Fragments (<>, <Fragment>), lifecycle hooks @onMount/@onUpdate/@onUnmount, and ref and key metadata.
  • Controlled form attributes (value / checked / selected, etc.) updated through the SAX DOM bridge; static style={{...}} is lowered to safe CSS text.
  • <Slot /> child projection and MUI-style slot context defaults (contextProps, contextScope="descendants").
NoteKnown boundaries: a full JS object prop ABI, full keyed reconciliation, and arbitrary JS expression object keys/spread are not yet done; select multiple currently represents the selected set as a comma/newline-separated string.
