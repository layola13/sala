pkg — Zero-Trust Package Manager

Zig 0.17This plugin is built with Zig 0.17: the 0.17 branch builds with Zig 0.17 and passes the Zig unit tests; the old 0.14.1 branch is kept unchanged.

sa_plugin_pkg is SA's package manager, playing the role of Rust's cargo/crates.io and npm, and is the SA ecosystem's main entry point for the general public: ordinary users mainly obtain, audit, and install dependencies through sa pkg. It performs zero-trust dependency management — fetching packages from remote sources (git ref + sha256 pinning), performing capability audits, generating locks and checksums, and writing them into the project.

Basic facts

  • Capability segment: package.management; no plugin dependencies; CLI-only (no .sai/.sal).
  • Permissions: read/write/create in the project directory; network only https://* GET and local GET; the child-process whitelist contains only /usr/bin/git.
  • Status: early / to be deepened. The command surface and zero-trust auditing are usable, but cargo-grade experiences such as a registry, semantic version range resolution, and a publish flow are still missing.

Commands

sa pkg install [--offline] [-g] [--ref REF] [identity]   # 解析并安装依赖
sa pkg fetch   [--offline] [-g] [--ref REF] <identity>   # 仅获取，不安装
sa pkg audit   [--format text|json] [--ci]
               [--allow-unaudited-risks] [--update-lock] <identity>

The sa.mod manifest

Dependencies are declared in sa.mod at the project root (the real syntax comes from src/pkg/manifest.zig):

require github.com/xiaoming/sa-ecs @v1.2.0 sha256:0123…cdef
require github.com/org/sa-net      @main   sha256:fedc…3210 grants [net_tx, net_rx]

[mirrors]
github.com = gitlab.corp.local/mirror
  • require <identity> @<ref> sha256:<digest> — one dependency with a pinned source;
  • grants [...] — the capabilities granted to that dependency;
  • [mirrors] — source mirror replacement (similar to cargo's source replace-with).

Zero-trust capability auditing

VerdictMeaning
UnauthorizedPrimitiveThe dependency used a primitive not covered by grants
UnauditedRiskBlockedHigh-risk and no authorization block written in sa.mod (blocked, or requires --allow-unaudited-risks)
UpstreamShaMismatchThe source content hash does not match the manifest
TransitiveSourceConflictA tampering conflict found while flattening the transitive dependency tree

Supporting modules: lock.zig (lock file), sum.zig (transitive dependency checksums), mirror.zig (mirror rules), ci.zig (CI gate). A high-risk dependency can only be used after an explicit authorization block carrying approved_machine_code_hashes is written into sa.mod.

NoteRelationship to the compiler core: at build time the compiler uses its own minimal parser (sci/src/pkg/resolver.zig) to resolve @import; pkg provides the upper-layer cargo workflow. Known technical debt: manifest/audit/fetch/lock/sum/mirror each exist in a copy in both the plugin and the core, and they have drifted, which may make the same sa.mod behave inconsistently under sa pkg install and sa build.
