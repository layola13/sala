vite — SAX 热重载开发服务器

sa_plugin_vite 是一个瘦编排插件：把「改了 .sax → 浏览器立即更新」的开发体验包装成 sa vite dev 命令。它不重新实现编译或 HTTP —— 编译复用 sax/react， 静态服务与 SSE 复用 http-server 的核心 API；自身只负责文件树监听、重建编排与实时信号端点。

基本事实

  • 能力段：vite.dev、vite.build、vite.preview；版本 0.1.0。
  • 依赖：sax（必需）、http-server（必需，且钉死了 18 个 sa_http_server_* 符号）。
  • 接口契约：vite.sai / vite.sal 提供 dev-session handle ABI （sa_vite_dev_new、sa_vite_dev_set_entry、sa_vite_dev_set_port、 sa_vite_dev_run、sa_vite_dev_stop 等 8 个 extern）。
  • 权限最小化：读项目目录、只在 $PROJECT/dist/** 写入；网络仅限本机 GET。

命令

命令说明
sa vite dev <entry.sax> [--react] [--include file.sax] [--out-dir dir] [--port p] [--debounce-ms n] [--title t] [--css f] [--public-dir d]启动 dev server + 递归监听 + 热重载；端口默认 5173，防抖默认 80ms
sa vite build <entry.sax> [--react] [--include file.sax] [--out-dir dir] [--title t] [--css f] [--public-dir d]一次性构建，生成可静态部署产物，不注入 live reload 客户端
sa vite preview [dist-dir] [--port p]预览已构建产物，不 watch、不重建；dist-dir 默认 dist

--css 会把样式表复制进 dist 并注入 link（dev 模式下监听它）； --public-dir 递归复制静态资源目录并在 dev 下监听变化。 修改 .sax/include 触发 wasm 重新编译；修改 css/public 资源只刷新资源并推送 reload，不重编 wasm。

热重载机制

dev 模式向生成的 index.html 注入同源脚本 /__sax_live_client.js； 浏览器经 /__sax_live（SSE）接收 reload/error 事件； 构建失败时页面显示错误浮层而不是白屏。

# 示例（在 sa_plugin_vite 目录内）
sa vite dev examples/counter.sax --out-dir /tmp/sa-vite-demo/dist \
  --port 5199 --debounce-ms 20 --title "SA Vite Demo" \
  --css assets/demo.css --public-dir public
注意与 JS/TS 工具链的关系：用户代码与 esbuild/tsc/node 物理隔离， 唯一的浏览器端 JS 是机器生成胶水（SAX 生成的 airlock.js 与注入的 reload 客户端），均非手写。 当前为 Phase 2 状态，实现路线见插件仓库的 plan.md 与 API_COVERAGE.md。
