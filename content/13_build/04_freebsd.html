FreeBSD 交叉编译

FreeBSD 是唯一需要“单独准备 sysroot”的目标，原因有三：Zig 0.14.1 官方不发布 FreeBSD 主机二进制；不捆绑 freebsd libc；zig build 没有 --sysroot 参数。为此 build.zig 新增了通用选项：

选项作用
-Dsysroot=<目录>设 b.sysroot，透传 --sysroot 给所有编译步骤
-Dlibc=<文件>设 b.libc_file，透传 -libc（libc 安装描述文件）

一键构建（推荐）

# 运行目录：sci 仓库根目录
sh tools/build_freebsd.sh
# 产物在 zig-out-freebsd/；可选参数：
#   --target x86_64-freebsd --prefix <输出目录> --sysroot <已有 sysroot>

脚本首次运行会自动下载 FreeBSD 14.4-RELEASE base.txz（约 155M） 解压为 sysroot，并生成 libc 描述文件（include_dir / sys_include_dir / crt_dir 指向 sysroot 内对应路径）。之后复用，不再下载。

手动构建

# 运行目录：sci 仓库根目录
SYSROOT=/tmp/fbsd/sysroot   # base.txz 解压目录，含 usr/include/stdlib.h
printf 'include_dir=%s/usr/include\nsys_include_dir=%s/usr/include\ncrt_dir=%s/usr/lib\nmsvc_lib_dir=\nkernel32_lib_dir=\ngcc_dir=\n' \
  "$SYSROOT" "$SYSROOT" "$SYSROOT" > /tmp/fbsd/libc.txt
zig build -Dtarget=x86_64-freebsd -Dllvm=false \
  -Dsysroot="$SYSROOT" -Dlibc=/tmp/fbsd/libc.txt -p zig-out-freebsd
file zig-out-freebsd/bin/sa
# 期望：ELF 64-bit LSB executable, x86-64, for FreeBSD 14.4, interpreter /libexec/ld-elf.so.1

FreeBSD 原生构建（替代路线）

在 FreeBSD 主机上用 ports 的 Zig（pkg install zig）直接原生构建， 不需要 sysroot：zig build 即可。但 sa_std.zig 含 Linux-specific 代码（io_uring/epoll 等），真机行为仍需逐项验证。

sa_std.zig 的 FreeBSD 兼容层

以下全是 Zig 0.14 标准库对 freebsd 的缺口，已在 src/runtime/sa_std.zig 内用 comptime builtin.os.tag == .freebsd 分支隔离，不影响其他平台：

  • TCP_NODELAY：std.posix.TCP 在 freebsd 上是 void， 直接写常量 1（Linux/macOS/FreeBSD 同值）；
  • hostname / os_release：std.posix.uname() 在 freebsd 上是 void， 改调 libc uname（FreeBSD struct utsname 五字段各 256 字节）；
  • IP 字面量解析：Address.resolveIp 与 Ip6Address.resolve 最终都走到未实现的 if_nametoindex，freebsd 下改用文件内数字解析器 （含 :: 压缩与内嵌 IPv4），命名 zone 用 FreeBSD libc 自带的 if_nametoindex 保持行为对等；解析器有单元测试，与 std 解析器 9 组向量逐字节一致。
