Error Codes and Diagnostics

This page explains SA's diagnostics system: the public trap names, the fields of the JSON diagnostic TrapReport, and the runtime ABI exit codes. After reading it you will be able to understand the JSON output of a failed compilation and locate the specific stage.

Basic Rules

  • Trap names are stable public identifiers; the ordinal of a trap enum is not a public numeric code — do not infer meaning from enum order.
  • Output is JSON-first structured diagnostics, not bare strings.
  • Semantic/syntactic failures are described by trap names defined in src/common/trap.zig.

Common Trap Categories (already emitted, not roadmap-only)

CategoryTrapTrigger scenario
Syntax / structureForbiddenSyntaxForbidden syntax such as {}, if, while appears; macro/import errors also mostly map here
DuplicateDef / DuplicateLabelDuplicate #def; duplicate label within the same function
FallthroughForbiddenA basic block does not end with a terminator instruction
Ownership / borrowingUseAfterMoveAccessing a register that has already been consumed (“moved value is no longer usable”)
BorrowConflict / DoubleMutableBorrow / ReadWriteConflictConflicting access or a second exclusive borrow on a locked source
MemoryLeak / EarlyReturnLeakLive registers remain at function exit or on a ? early-return path
StackEscape / InteriorPtrEscapeA stack allocation escapes a native boundary; an interior pointer crosses an FFI boundary
TransferIntoBorrow (1061) / TransferIntoImmutable (1062)The target of transfer c, v is not a live owned root container (a borrow/interior pointer, or an @const/immutable binding)
ContractCapabilityMismatchThe prefix at the call site does not satisfy the callee contract
FallibleContractMismatchUsing ? on a non-fallible value, or a fallible return path mismatch
ConstMutation / FfiOwnershipViolation / IllegalUnsafeContextRewriting an @const; applying ^/! to an FFI view; an airlock instruction appearing outside an @ffi_wrapper
AtomicsInvalidAtomicOrdering / AtomicOrderingMismatchAn illegal ordering combination at the flattener stage; a same-address RMW ordering not allowed at the Referee stage
OtherImportResolutionFailed, MacroRecursionLimit (depth > 256), UnsupportedType, ArenaOOM, etc.See the full table in the official error-code document
NoteGasExceeded, SnapshotVersionMismatch, and VTableSignatureMismatch are currently reserved namespaces, not yet wired into the current pipeline (roadmap-only); do not expect them to appear when troubleshooting.

Quick Stage Attribution

  • An error from flattener mapping (mostly the ForbiddenSyntax family) → the text parsing/macro expansion stage.
  • Structured JSON with mask fields → the Referee (src/referee/verifier.zig is the main emitter).
  • The error: <name> form → an interpreter / driver internal error, currently not an SA Trap JSON.
