io 与 print：标准输入输出

这一页列出 sa_std/io/print.sai 与 sa_std/io.sai 导出的 extern 函数： 标准流访问、按行读取、带长度读写，以及最常用的 println。 读完即可在 Sla 程序里完成基本的控制台输入输出。

导入

@import "sa_std/io/print.sai"   // 仅打印（demo/简单程序）
@import "sa_std/io.sai"          // 完整 io 面

io/print.sai 是面向 demo 的旧契约，实现上等价于 stdout().write_all(bytes)； io.sai 是完整契约。Sla 代码里的 println(...) 调用由编译器 lower 到这套 stdout 写入。

函数签名（摘自 io.sai / io/print.sai）

签名说明
sa_print_bytes(&msg: ptr, len: u64) -> void把字节写到 stdout（print.sai 旧契约，兼容 demo）
sa_io_stdin() -> u64stdin 句柄（借用，勿 close）
sa_io_stdout() -> u64stdout 句柄（借用，勿 close）
sa_io_stderr() -> u64stderr 句柄（借用，勿 close）
sa_std_println(&msg: ptr, len: u64) -> i32!Zig 后端 stdout 写入的便捷打印
sa_io_read_line(handle: ptr, max_bytes: u64) -> ^ptr!读一行，返回 owned 指针
sa_io_read(handle: u64, &buf: ptr, cap: u64, &out_read: ptr) -> i32读最多 cap 字节，实际长度写入 out_read
sa_io_read_exact(handle: u64, &buf: ptr, len: u64) -> i32精确读满 len 字节
sa_io_write(handle: u64, &buf: ptr, len: u64, &out_written: ptr) -> i32写 buf，实际写入量写 out_written
sa_io_write_all(handle: u64, &buf: ptr, len: u64) -> i32循环写满全部字节
sa_io_flush(handle: u64) -> i32刷新句柄缓冲
sa_io_close(handle: u64) -> i32关闭 owned 句柄
sa_io_buffer_data(&buffer: ptr) -> &ptrSaIoBuffer 数据指针
sa_io_buffer_len(&buffer: ptr) -> u64SaIoBuffer 长度
sa_io_buffer_free(^buffer: ptr) -> i32!释放 owned SaIoBuffer

调用示例（来自 demos）

摘自 demos/rosetta/01_hello_world/main.sla：

@import "sa_std/io/print.sai"
@import "sa_std/fmt.sai"
@import "sa_std/string.sa"

fn main() -> i32 {
    println("hello, saasm");
    return 0;
};

println 支持格式占位与多参数（配合 fmt，见 fmt 一章）， 摘自 demos/rosetta/04_loop/main.sla：

fn main() -> i32 {
    let buffer = [1u8, 2, 3, 4];
    let zeroed = fill_zero(buffer);
    println("[{},{},{},{}]", zeroed[0], zeroed[1], zeroed[2], zeroed[3]);
    return 0;
};
注意sa_io_read_line 返回 owned 指针、需要释放；而三个 std 流句柄是进程借用的，调用 sa_io_close 属于误用。
