io and print: Standard Input/Output

This page lists the extern functions exported by sa_std/io/print.sai and sa_std/io.sai: standard stream access, reading by line, length-based reading and writing, and the most commonly used println. After reading it, you will be able to do basic console input/output in an Sla program.

Importing

@import "sa_std/io/print.sai"   // 仅打印（demo/简单程序）
@import "sa_std/io.sai"          // 完整 io 面

io/print.sai is an old contract aimed at demos, and is implemented as equivalent to stdout().write_all(bytes); io.sai is the complete contract. A println(...) call in Sla code is lowered by the compiler to this set of stdout writes.

Function Signatures (from io.sai / io/print.sai)

SignatureDescription
sa_print_bytes(&msg: ptr, len: u64) -> voidWrite bytes to stdout (old print.sai contract, compatible with demos)

sa_io_read_line(handle: ptr, max_bytes: u64) -> ^ptr!Read one line, returning an owned pointer
sa_io_read(handle: u64, &buf: ptr, cap: u64, &out_read: ptr) -> i32Read at most cap bytes; the actual length is written to out_read
sa_io_read_exact(handle: u64, &buf: ptr, len: u64) -> i32Read exactly len bytes
sa_io_write(handle: u64, &buf: ptr, len: u64, &out_written: ptr) -> i32Write buf; the actual amount written is written to out_written
sa_io_write_all(handle: u64, &buf: ptr, len: u64) -> i32Loop until all bytes are written
sa_io_flush(handle: u64) -> i32Flush the handle's buffer

Call Examples (from the demos)

From demos/rosetta/01_hello_world/main.sla:

@import "sa_std/io/print.sai"
@import "sa_std/fmt.sai"
@import "sa_std/string.sa"

fn main() -> i32 {
    println("hello, saasm");
    return 0;
};

println supports format placeholders and multiple arguments (together with fmt; see the fmt chapter), from demos/rosetta/04_loop/main.sla:

fn main() -> i32 {
    let buffer = [1u8, 2, 3, 4];
    let zeroed = fill_zero(buffer);
    println("[{},{},{},{}]", zeroed[0], zeroed[1], zeroed[2], zeroed[3]);
    return 0;
};
Notesa_io_read_line returns an owned pointer that needs to be released; the three standard stream handles are borrowed from the process, and calling sa_io_close on them is misuse.
