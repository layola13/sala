env：环境变量与目录

这一页列出 sa_std/env.sai 导出的 extern 函数：读写环境变量、获取工作目录 / home / 临时目录、以 JSON 形式批量读取参数与环境，以及 XDG 目录族。 读完即可在程序里处理配置来源与路径列表。

环境变量

签名说明
sa_env_get(key: ptr, key_len: u64) -> u64取变量值，返回 owned 缓冲句柄（未设置时为空句柄）
sa_env_has(key: ptr, key_len: u64) -> i32变量是否存在
sa_env_set_var(key: ptr, key_len: u64, value: ptr, value_len: u64) -> i32设置变量
sa_env_remove_var(key: ptr, key_len: u64) -> i32移除变量
sa_env_args_json() -> u64命令行参数，JSON 数组缓冲
sa_env_vars_json() -> u64全部环境变量，JSON 对象缓冲

目录与路径

签名说明
sa_env_current_dir() -> u64 / sa_env_set_current_dir(path: ptr, path_len: u64) -> i32查询 / 设置当前目录
sa_env_temp_dir() -> u64 / sa_env_home_dir() -> u64 / sa_env_current_exe() -> u64临时目录 / home 目录 / 当前可执行文件路径
sa_env_split_paths_json(path_list: ptr, path_list_len: u64) -> u64按平台分隔符切分 PATH 型字符串，返回 JSON 数组
sa_env_join_paths_json(paths_json: ptr, paths_json_len: u64) -> u64把 JSON 路径数组拼回 PATH 字符串
sa_env_xdg_data_home_dir() / _config_home_dir() / _state_home_dir() / _cache_home_dir() / _data_dirs() / _config_dirs()XDG 规范目录族，均返回 owned 缓冲句柄

缓冲三件套

@extern sa_env_buffer_data(buffer: u64) -> &ptr
@extern sa_env_buffer_len(buffer: u64) -> u64
@extern sa_env_buffer_free(^buffer: u64) -> i32

所有返回 u64 的 env 函数都遵循这一约定：先 _data/_len 读内容，再用 _free 释放。

SA 层调用形式

契约中的 extern 直接对应运行时符号，例如判断变量存在并取值的调用形如：

%has = call @sa_env_has(&%key, %key_len)
%buf = call @sa_env_get(&%key, %key_len)
%ptr = call @sa_env_buffer_data(%buf)
%len = call @sa_env_buffer_len(%buf)
注意Sla 代码需先 @import "sa_std/env.sai" 才能使用这些函数； sa_env_get 返回的句柄必须释放。
