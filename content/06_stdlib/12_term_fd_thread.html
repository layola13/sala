term / fd / thread / testing

This page brings together four smaller contracts: term.sai (terminal raw mode and the epoll event loop), os/fd.sai (raw file descriptors), thread.sai (threads) and testing/assert.sai (assertions). After reading it, you will be able to do TUI/event loops, fd conversion, concurrency and unit testing.

term.sai: Terminal Control and epoll

Raw-mode sessions and epoll instances are both owned ptrs that must be closed explicitly.

SignatureDescription
sa_term_raw_enter(handle: ptr) -> ^ptr!Enter raw mode, returning a session handle
sa_term_raw_leave(^session: ptr) -> i32!Leave raw mode and release the session
sa_term_winsize(handle: ptr, &out_size: ptr) -> i32!Query the terminal window size
sa_term_epoll_create(flags: u32) -> ^ptr!Create an epoll instance
sa_term_epoll_ctl(epoll: ptr, op: u32, target: ptr, events: u32, data: u64) -> i32!Register/modify/remove a watched target handle
sa_term_epoll_wait(epoll: ptr, &events: ptr, max_events: u64, timeout_ms: i32, &out_count: ptr) -> i32!Wait for events, with a timeout in milliseconds
sa_term_epoll_close(^epoll: ptr) -> i32!Close an epoll instance

SignatureDescription
sa_std_fd_as_raw(handle: u64, &out_fd: ptr) -> i32 / sa_std_fd_from_raw(fd: i32, &out_handle: ptr) -> i32Convert between a handle and a raw fd (there are also _into_raw, _dup_raw)
sa_std_fd_dup(handle: u64, &out_handle: ptr) -> i32Duplicate a handle
sa_std_fd_close_raw(fd: i32) -> i32Close a raw fd
sa_std_fd_is_terminal(handle: u64, &out_flag: ptr) -> i32Whether it points to a terminal

thread.sai: Threads

A handle is an opaque i32 slot held by the runtime.

SignatureDescription
pthread_spawn(*entry: ptr, *arg: ptr) -> i32 / pthread_spawn_detached(...) -> i32Create a joinable / detached thread
pthread_join(handle: i32, *out: ptr) -> i32 / pthread_drop(handle: i32) -> voidJoin, or simply discard the handle
sa_thread_current_id() -> u64 / sa_thread_yield_now() -> i32Current thread ID / yield scheduling
sa_thread_as_pthread_t(handle: i32, &out_raw: ptr) -> i32 etc.Convert to and from a native pthread_t; sa_thread_raw_pthread_join(raw: u64, *out: ptr) joins a native handle directly

testing/assert.sai: Test Assertions

SignatureDescription
sa_assert_eq_i64(actual: i64, expected: i64, code: i32) -> voidi64 equality assertion; panics with code on failure
sa_assert_eq_i64_at(actual: i64, expected: i64, code: i32, &file: ptr, file_len: u64, line: u32, col: u32) -> voidVersion with source location
sa_test_debug_i64(&name: ptr, name_len: u64, value: i64) -> voidOutput a debug value during testing
sa_test_fallible_i32_value(value: i32) -> i32!Wrap a plain i32 as a fallible value for testing

Sla's test entry point is an @test "名字"() { ... } block, used together with panic(code) to express failure, for example:

@test "rosetta 004 04_loop"() {
    let got = zeroed_buffer_sum();
    if got != 0 {
        panic(4);
    };
};
NoteSynchronization primitives (Mutex/RwLock/Condvar/Barrier/ atomic/Mpsc/Once) live under sa_std/sync/, and are all .sa/.sal macro contracts rather than externs; for example, the demos 121_rwlock_reader_writer, 122_condvar_wait_notify and 123_barrier_sync are implemented on top of them.
