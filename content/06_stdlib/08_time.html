time: Clocks, Time, and Sleep

This page lists the extern functions in sa_std/time.sai, and gives real usage of Instant / Duration / SystemTime on the Sla side. After reading it, you will be able to measure elapsed time and put a thread to sleep.

Clock Conventions (TS-17, Written 2026-10-29)

The time domain is a two-clock division, stated as follows: sa_time_instant_ns is a monotonic clock (a clock relative to a process origin); runtime task timing also uses the monotonic clock — task / select timeouts and sleep timing are all in monotonic terms (CLOCK_MONOTONIC), and sa_time_sleep_ns sleeps for a duration by this clock; the sa_time_unix_* family is a wall clock (real time); calendar field decomposition and sa_time_format_utc are in UTC terms.

The TS Frontend (the satsgo Date Chain)

satsgo narrows Date to an i64 millisecond value (a UTC subset, no time zones): Date.now() / a no-argument new Date() call sa_time_unix_ms directly; getTime is the identity; toISOString / the get family / the setter family route to the three rows in the table above, respectively; getTimezoneOffset is always 0; parse and format forms other than new Date(x) / Date.parse (RFC2822, two-digit years, locale strings) are all rejected loudly. An invalid ISO value panics at Date.parse (NaN is not representable in an i64). Porting note: the call shapes emitted by satsgo align bit-for-bit with the signatures in the table above, enforced mechanically by tools/check_sa_std_projection.sh.

Type Surface on the Sla Side

Sla code uses the names SystemTime / Instant / Duration, which the compiler lowers to the time contract. A real example is from demos/rosetta/09_async_await/main.sla:

@import "sa_std/time.sla"

fn unix_now_millis() -> u64 {
    return SystemTime::now().duration_since(SystemTime::unix_epoch()).unwrap().as_millis();
}

fn sleep_for_millis(delay_ms: u64) -> void {
    thread::sleep(Duration::from_millis(delay_ms));
}

fn instant_now_ns() -> u64 {
    let started = Instant::now();
    return started.raw_ns();
}

fn elapsed_millis_since_ns(started_ns: u64) -> u64 {
    let started = Instant::from_raw_ns(started_ns);
    return started.elapsed().as_millis();
}

The visible correspondences: Instant::now().raw_ns() is the monotonic nanosecond value (sa_time_instant_ns), Instant::from_raw_ns rebuilds from a raw nanosecond value, and Duration::from_millis(ms).as_millis() constructs and reads a duration at millisecond granularity.

NoteThe contract comment states explicitly: sa_time_utc_now returns a plain i32 status code rather than a Fallible {status, value}; the caller must judge success or failure by the status code, and the calendar fields are returned through the &out pointer.
