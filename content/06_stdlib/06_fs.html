fs: Files and Directories

This page introduces the file reading/writing, whole-file reading, directory traversal and metadata functions in sa_std/fs.sai, and the corresponding macro wrappers on the Sla/SA side. After reading it, you will be able to open a file, read and write its contents, and read a whole file into a memory buffer.

Importing

@import "sa_std/fs.sai"   // extern 契约
@import "sa_std/fs.sa"    // SA 宏（Sla 方法面经此 lower）

SA Macro Forms (Excerpt from fs.sa)

Macros wrap extern calls into a multi-return-value form, for example:

[MACRO] FS_READ_TO_STRING %out_status, %out_buffer, %path, %path_len, %max_bytes
[MACRO] FS_OPEN_READ      %out_status, %out_file, %path, %path_len
[MACRO] FS_WRITE_FILE     %out_status, %path, %path_len, %buf, %len
[MACRO] FS_READ_BUFFER_DATA %out_ptr, %buffer
[MACRO] FS_EXISTS         %out_flag, %path, %path_len
[MACRO] FS_METADATA_IS_FILE %out_flag, %metadata

A Real Example

The Sla-side wrapper macro is from sa_plugin_sla/tests/import_fixtures/pkgjson/fs_helpers.sa:

@import "sa_std/fs.sa"

[MACRO] SLA_FS_READ_TO_STRING %out_buffer, %path, %path_len, %max_bytes
    __sla_fs_read_status_%out_buffer = 0
    EXPAND FS_READ_TO_STRING __sla_fs_read_status_%out_buffer, %out_buffer, %path, %path_len, %max_bytes
    !__sla_fs_read_status_%out_buffer
[END_MACRO]

An example of using macros directly at the SA layer is from demos/rosetta/181_file_descriptor_raii/main.sa (constructing an Err when opening fails):

@const SLA_STR_0 = utf8:"/dev/null"
EXPAND SLICE_NEW tmp_1, &SLA_STR_0, tmp_2
EXPAND FS_OPEN_READ tmp_5, tmp_6, tmp_3, tmp_4
tmp_8 = eq tmp_5, SA_FS_OK
br tmp_8 -> L_FILE_OPEN_OK_0, L_FILE_OPEN_ERR_1
WarningWhole-file reading is protected by the max_bytes limit, and returns an owned buffer handle; after use you must call the corresponding _free, otherwise the buffer leaks.
