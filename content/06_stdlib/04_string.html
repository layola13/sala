string：ASCII / UTF-8 字符串

这一页列出 sa_std/string.sai 的 extern 函数，以及 sa_std/string.sa 提供的字符串宏族。读完即可判断字符串是否 ASCII、统计与遍历 UTF-8 字符、做大小写无关比较和拼接。

extern 函数（摘自 string.sai）

签名说明
sa_str_is_ascii(ptr: ptr, len: u64) -> i32字节序列是否全为 ASCII
sa_str_eq_ignore_ascii_case(left: ptr, left_len: u64, right: ptr, right_len: u64) -> i32忽略 ASCII 大小写比较
sa_str_trim_ascii_start_index(ptr: ptr, len: u64) -> u64计算去除首部空白后的起始下标
sa_str_trim_ascii_end_len(ptr: ptr, len: u64) -> u64计算去除尾部空白后的长度
sa_str_utf8_char_count(ptr: ptr, len: u64) -> u64统计 UTF-8 字符数
sa_str_utf8_validate(ptr: ptr, len: u64) -> i32校验 UTF-8 合法性
sa_str_utf8_char_at(ptr: ptr, len: u64, char_index: u64, out_codepoint: ptr) -> i32按字符下标取码点
sa_str_utf8_char_at_byte(ptr: ptr, len: u64, byte_index: u64, out_codepoint: ptr, out_len: ptr) -> i32按字节下标取字符（码点 + 编码长度）
sa_str_utf8_lossy_next(ptr: ptr, len: u64, byte_index: u64, out_codepoint: ptr, out_len: ptr) -> i32从字节下标起取下一个字符，非法序列按 lossy 处理
sa_str_utf8_char_range_at(ptr: ptr, len: u64, char_index: u64, out_start: ptr, out_len: ptr) -> i32取第 n 个字符的字节范围
sa_string_concat(left: ptr, left_len: u64, right: ptr, right_len: u64) -> u64拼接两段字节，返回 owned 缓冲句柄

SA 宏（string.sa，节选）

string.sa 是 Sla String/str 方法面的实现载体， 常用宏包括：

宏说明
STR_LEN %out_len, %slice_reg取长度
STR_PTR / STR_AS_PTR %out_ptr, %slice_reg取数据指针
STR_IS_EMPTY %out_bool, %slice_reg是否为空
STR_FROM_PARTS %out_slice, %data_ptr, %length由指针 + 长度构造切片
STR_FROM_CONST %out_slice, %const_label, %const_len由常量标签构造切片（alloc/string.sa）
STRING_NEW %out_slice新建可变 String
STR_TRY_FROM_UTF8 / STR_FROM_UTF8 %out_ok, %out_slice, %bytes_slice从字节数组构造，带校验/不带校验
STR_AS_BYTES %out_slice, %slice_reg转字节视图

Sla 侧示例

字符串比较在 Sla 里通过 str_eq 使用。摘自 demos/rosetta/01_hello_world/main.sla 的测试：

@import "sa_std/io/print.sai"
@import "sa_std/fmt.sai"
@import "sa_std/string.sa"

@test "rosetta 001 01_hello_world"() {
    if str_eq("hello, saasm", "hello, saasm") != true {
        panic(1);
    };
};
注意sa_str_* 函数都接受 裸的 (ptr, len) 而不是字符串对象；sa_string_concat 返回的 owned 缓冲句柄需要显式释放。
