一、定位与唯一问题

这门语言只解决一个问题：让违反守恒律与热力学第二定律的反应网络模型在写出时即不可写。一句话版：让违反物理的模型像类型错误一样，在写出来的那一刻就报错。

病灶在现行建模实践：正、逆速率常数成对填写、配平靠手、能量多处来源彼此不校——元素不守恒、循环平衡常数自相矛盾（封闭系统内的永久环流，即第二类永动机）这类错误都能「跑起来」，只能靠模拟结果反常再倒查，且查不干净。本语言的应对是把能量立为唯一真相源：速率常数一律由能量按草案 §2.2 推导，用户永远不直接写一对 (kf, kr)；Wegscheider 循环条件因此由构造战立，C2 只需检查绕过构造的写法；配平与电荷由 C1 在写出时即查（草案公理 4：守恒先于表达力）。

由此得出本语言的本体论：检查器即是这门语言的价值本体。草案 §7 的首个实现只有静态检查器、没有模拟器，这不是范围简化，而是定位本身——哪怕它永远只做检查，要解决的问题也已经解决。模拟、观察、模块组合都是在这一保证之上的第二层。

全覆盖验证：目标的完整形态（2026-10-29 升格裁决）

用户裁决：目标就是解决「所有题目都可以验证」——以高考生物化学的全部题型为验收面。立论：高考题目在设计上即自带参考答案与评分标准（踩点给分），凡有显式评分细则者，皆可编码为断言集；凡可编码者，皆可判定。因此覆盖的边界不是「形式语言 vs 自然语言」，而是「有没有显式评分标准」——而高考恒有。本语言语境下，验证即对显式编码的断言集做判定，判定分三层，层与层之间以溯源区分、不以覆盖区分：

  • 第一层：核心演算机械判定。C1–C6 静态检查与计量、平衡求解——结论由物理与数学构造性推出，无人为判断成分。
  • 第二层：领域演算模块。核心演算之外的小演算，各自封闭、精确、可判定：遗传概率演算（等位基因、配子与概率）、氧化数约定层、有机同分异构枚举、实验协议判定（见下表）。
  • 第三层：评分要点 extern。论述、现象描述、实验分析等自然语言得分点：评分细则被编码为结构化断言（必备概念、概念间关系、典型错误形态），由预言机判定。按草案公理 5，这类判定必须以 extern 显式声明、并在 C6 溯源中标注为 extern 来源——总性靠覆盖，诚实靠溯源：可以全覆盖，但 extern 判定绝不冒充核心推导。

二、出发点：教育——检查器即老师

用户定出发点：一门生物化学的编程语言，由浅入深，覆盖初中、高中、大学课程，能编写、能检验。检查器即时指出哪里不守恒、哪里违反热力学、为什么——反馈即教学，检查器即老师。

形态为同一核心、分级开放：每一级是核心演算的子集，配该级的话术层；高级不推翻低级，只是解锁更多构造与更深的语义。

分级通则三条：

  • 子集单调，低级别永不被推翻：守恒一条线从 L0 的质量守恒定律贯穿到 L4 的 Wegscheider 条件——课程的由浅入深与物理的由浅入深是同一条线。
  • 习题即断言：低级别以「检查通过」为题型；L2 起 observe 断言即考题，判定结果附 C6 假设清单，自动批改与「你的结论依赖哪些假设」一次完成。
  • 报错话术按级分级：同一错误码、不同话术层——L0 用最具体的课本语言（逐元素报差：「左边 2 个氧原子，右边 1 个」），级别升高逐步过渡到矩阵与零空间术语。草案的命名错误码 + 同源错误合并 + 补救提示（如漏 H+ 时 C1-element 与 C1-charge 合并报告）是这一分级的底座。
  • 断言来源即评分标准：题目的断言集与评分要点由教师按考试评分细则编码（见一节全覆盖验证）——低级别以检查通过为题型，高级别以断言判定为题型，判分形态与真实考试的踩点给分同构。

三、架构裁决

形态升格：引擎 + 语言（2026-10-29 裁决）

用户裁决：要做的是生化引擎，而不仅仅是一门语言。结构定为：引擎是本体，语言是引擎的表层与契约面。核心演算是引擎的物理宪法——引擎的一切行为（求解、判分、模拟）不得违反它；语言是人把模型与题目写进引擎的唯一通道——教师编题、学生作答、研究者建模都经由语言，不存在绕过语言直达引擎内部的第二入口。这一结构与本生态既有三层同构：核心演算之于引擎，如 SA 之于 sa_std；语言之于引擎，如 SLA 之于 SA——下层冻结、只立宪法，上层演进、承载用法。

引擎五部件：

部件内容首现期
知识底座物种与能量数据库：元素与化合价表、物种 G° / H°、课程方程式库。身份内容寻址、带版本号（见四节补遗二）与 C6 来源标签；数据本身须交叉核验后入库期一

有限性是可行性根基。教育定位使知识底座成为有限集：初中、高中课程标准与考试说明实际枚举的物种与反应在数百量级，大学普化与生化再扩一档，仍属可逐条人工审校的有限库——引擎的数据长尾被课程边界截断。这与开放世界建模（任意物种、任意反应的通用化学平台）有量级之别，也是「引擎」二字在本计划中可行的前提。

在此形态下，原架构裁决各条全部保留、细化如下。

  • 语义核心全新，不建在 SA 上。SA 是寄存器 + 所有权的系统级机器，其指令、内存与调用语义同化学计量、图重写、CTMC 没有交集；把核心演算压到 SA 上，是让化学迁就一台为系统编程造的机器，两边都会坏。SA 冻结 doctrine 不变、不为任何前端让路；本语言的演算（草案全文）就是它自己的底座。SA 在这里是脚手架，不是地基。
  • 工程外壳寄生 SA 生态。新语言注册为宿主的一个 kind=language 前端、按扩展名分发，与 SLA、slars 平级，不另起工具链；扩展名于开工时定。表层丰富性一律以脱糖进入核心且展开可审计（沿本栈 syntax lowering 的纪律）；脱糖在管线中的位置逐构造定死——例如 C5 必须挂在 catalyst 脱糖之前，因为脱糖后催化关系即不可见（草案 §3.5）。
  • 实现语言：SLA 优先。检查器是纯计算批处理（解析、建图、检查、出诊断），与 sla convert 同一类负载，是 SLA 最擅长的形态；以自家语言实现自家的新前端，分发、诊断与语料纪律全现成，且图算法与数值面正好压在 CXU 压不到的 SLA / std 部位——撞出的缺口直接回流 std 改进队列。
  • 两个重核与下沉规则。重核一：分子图规范化（WL 细化 + 个体化-细化回溯，草案 §7.3；P1 期可先与 RDKit 规范 SMILES 做对照测试）。重核二：精确有理数线性代数（零空间、极小半流；浮点舍入会丢守恒律，禁用浮点，草案 §7.3）。sa_std 目前没有大数 / 有理数，列为开工先行补齐的一小块 std；若某核在 SLA 里性能或表达力撑不住，按「核心进 std」doctrine 下沉为 sa_std 的 extern 核、表面保持 SLA——是下沉，不是换语言。
  • 模拟层借运行时、不借语义。将来的模拟后端消费的是网络生成阶段产出的反应网络（数据）；SMC 需要成千上万条独立轨迹，其并行借 goroutine 运行时（13 号）承载，与 SA 的机器语义无关。
  • 建议管线序：解析 → 规范化与物种解析（身份在此定死）→ 脱糖（C5 挂脱糖前）→ C1–C6 依依赖序检查 → 网络生成（逐物种级反应记录 n+ / n−，草案 §2.5）；每一阶段的中间产物（脱糖后核心、反应网络、化学计量矩阵）都可导出，问题定位靠中间面可见。

四、对草案 v0.2 的工程补遗

以下四项为本计划新增、草案未含，开工时并入规范：

  • 单位进类型系统。量纲检查之于本语言，如所有权检查之于 SLA：草案 §2.2 中 (c°)1−m 这类标准态因子错一次、整个速率常数即错，正是量纲检查要杀死的 bug 类。浓度、体积、能量、时间等量至少在字面量与能量 / 浓度 / 体积运算处可验。
  • canon 身份带版本号。规范化算法的版本号必须进入 species_id 的计算域。教训来自本栈 .sla-cache：其宏索引缓存键不含编译器版本，旧缓存曾掩盖新编译器行为；canon 每改一次全域物种身份皆变，不带版本即是身份毒害。
  • extern 预言机必须进契约面。序列→折叠→功能这类外部预言机（草案公理 5、C6 的 extern(name) 标签）须在一等契约面声明签名与不确定性形态，否则 C6 溯源传播会在 extern 边界断裂——草案 §8 第 6 条的不确定性传播问题有一半是这个工程问题。教训：sa_deno 23 个符号只有 3 个有 .sai 契约、其余活在契约宇宙之外，契约层管不到。评分要点判定（见一节第三层）同属 extern 一类、同样适用本条：判定接口与不确定性形态须进契约面，其结果在 C6 中与核心推导分区标注。
  • 反馈协议定性为相变项，一期不做。草案 §8 第 3 条（协议层读采样值决定下一步）一旦允许，协议层即从事件列表变成真正的命令式语言，须与物理层随机语义做隔离设计——量级如一门小语言自身的立项，不顺手添加。v0.2 协议层保持纯事件列表（草案 §1.9、§6）。

  • 期一：引擎 v0.1——最小闭环先行。判据修订：知识底座 + 检验运行时 + 语言面三者齐备，才算 v0.1；原「检查器单件先行」的表述就此改掉——没有数据的检查器验不了课程题目，没有语言面的引擎进不了课堂。内容：知识底座 v0.1（初中、高中常用物种与课程方程式库、元素与化合价表，逐条带 C6 来源标签、交叉核验后入库）+ 检验运行时（草案 §7 检查链：P1 物种层（SMILES 解析、规范化、species_id，与 RDKit 对照）→ P2 C1 → P3 化学计量矩阵 + C2 / C3 → P4 C4 / C5 → P5 agent 层 + 模块粘合 M1 / M2；C6 只做标签传播、不做报告格式化）+ 题目与判分运行时最小形态（以「检查通过」为题型的判分）+ L0 / L1 语言面（化学式表层、初中化合价表、L0 / L1 两层报错话术）。先行件：sa_std 大数 / 有理数小块。
  • 期二：求解与判定扩面 + L2 / L3。平衡求解器（平衡组成、pH、水解）落地，L2 起 observe 数值断言全面可判定；观察求值以统计模型检验（SMC）为一般方法（草案 §5.2），结果附方法、样本量与 C6 假设集合；领域演算模块首批：遗传概率演算、氧化数约定层；extern 接口层首版：评分要点判定接入题目与判分运行时，全覆盖三层机制至此合成（三节部件表）；教育面落能量块表层、catalyst 与 module 教学样例库（糖酵解课程项目为旗舰样例）。
  • 期三：模拟与呈现 + L4。引擎的模拟与呈现部件落地：后端含 SSA 精确模拟、tau-leaping、ODE / LNA，呈现含浓度曲线与通路图；语义只有一个（CTMC），其余皆是近似（草案 §2.6）——多后端之间以差分对拍验收，无网络 SSA 与网络生成 CTMC 的一致性（Danos 等 2007）为基准。领域模块补有机同分异构枚举。教育面补齐 L4 全形态。

验收纪律沿用本仓通则：各级样例同时就是回归语料（草案 §7.2 已定此例）；检查类修复必须带最小复现语料，且在独立的基线树上验证「修复前失败、修复后通过」；套件判读比对失败名字集，不看通过 / 失败计数。
