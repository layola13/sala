SLA 插件提供的命令

下表以顶级 sla 命令书写；每种写法都有 sa sla … 等价形式 （去掉前缀即互换），详见「命令行参考」章节。

命令作用

sla skills [--json]列出 SLA 插件能力；文本模式还会写入 skill 文件到当前目录

TS 前端：sa_plugin_ts 与 tsgo-sa（satsgo）

仓库内有两个 TypeScript → SA 前端：sa_plugin_ts（手写词法/解析， 子集明确，286 个 demo 全过 sa check）与 tsgo-sa （satsgo，复用生产级 TS 解析/绑定/检查器，目标是替代前者）。 两者共同纪律：拒则大声——不在子集的一律报定位错误， 绝不静默错译；标准库一律复用 sci/sa_std 或插件原生后端， 前端零运行时模拟（tools/check_sa_std_projection.sh 机器强制）。

  • 多文件链接（tsgo-sa build）：import 图 + 可达集， 值循环拒绝并给出链；import type 边与“仅类型位使用”的 value import 边自动擦除；export default {..} / export default ns 命名空间对象按成员直达定义； package.json 依赖记入 sa.mod 注释与报告 （require 行需 sha256，无 hash 不输出有效行）。
  • 类型驱动布局：结构体布局优先记录表，缺失时查检查器 （工厂返回等推断类型、匿名形字段集）；type X = {..} 别名建布局， 嵌套链按字段偏移下沉。
  • 守卫与窄化：?. 按可空性加 join； typeof v === "undefined" 降为 null 检查（子集 null/undefined 统一为 0）； Date 窄化为 i64 毫秒（UTC）， now/getTime/toISOString/parse/get 系/setter/toString 系 投影到 sa_std/time.sai（见标准库 time 页）。箭头函数捕获走共享用名分析 （类型名不进捕获）；typeof 未知名的“unknown global”判定经 binder 可见性（自建 scope 仍管所有权，binder 只答可见性）。
  • Node/Deno 投影：os/path/crypto/Hash/url/querystring/util/console/Buffer 与 Deno.* 按调用形状投影到 node.sai / deno.sai 原生符号（u32 状态检查，非零 panic）；异步（timers 等）与缺件保持大声拒。 完整表面见“插件参考 > node”页第九节。
  • TSX：静态模板直出 .sax；useState 进 state 槽、挂载期 useEffect（空体/ setter 常量）进 @onMount；document.createElement/appendChild/setAttribute、 createTextNode、textContent/innerHTML 读写与 el.textContent 读（调用方 scratch + 满缓冲 panic）投影到 airlock DOM extern；其余 hooks/动态形态一律大声拒。
  • 拒则大声的名录：异步定时器（setTimeout 等 6 个， 缺事件循环，Phase 2）、toLocale*（缺 locale 后端）、非 ISO 的 Date.parse（panic，非 NaN）、动态 Buffer.concat 数组、 format/inspect（缺编码器/类型守卫）。用户同名定义永远优先于 上述拒绝（影子规则）。

Agent-first 的宿主命令

sci 面向 Agent 设计了一组自解释命令：全局 --json 输出结构化诊断 （稳定错误码如 SA-REF-010，附 repair 建议）、compile_tokens / instruction_count 指标，以及 explain <code>、 fix --plan --json、skills 等子命令。 skills 会聚合当前启用插件的语法、宏与 API 契约，文本模式下刷新 .codex/skills/… 与 .claude/skills/… 文件； 使用前仍应通过 sa plugin list 或 sa skills --json 确认插件已启用。

sa_std 的位置

标准库随 sci 仓库发布，位于 <sci 根目录>/sa_std/， 包含 .sa 实现、.sai 接口契约与 .sal 宏， 按模块分子目录（io、collections、mem、 sync、text、os 等）。Sla 通过 @import "sa_std/…" 直接引用。预构建产物另有 artifacts/sa_std/libsa_std.a。解析顺序： 环境变量 SA_STD_DIR 优先，否则回退到 $HOME/projects/sci/sa_std。

各插件命令的完整参数说明见「命令行参考」与「插件参考」章节。
