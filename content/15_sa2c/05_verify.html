2. 修过的代表性问题

  • 间接分发空表恒 trap（uint64_t idx >= 0 恒真），demo 466 回归。
  • 500+ 死 helper（NOLINT 压警告属作弊）：改按需发射＋可达性裁剪。
  • u64 别名 rem/gt 误走 signed（demo 388/389）、i32 lshr 未窄化（347）、 f32 链 domain 污染（452）、间接 f32 返回比较（472）。
  • demos/c/219 镜像缺 bin/ 子树（另被 demos/**/bin/ ignore 误伤，照 rosetta 原件 git add -f 补齐）。

3. 已知边界（非 bug，按设计）

  • 未知 extern 仍是精确 trap（sa_trap("extern …")），调用前按需发射、无死代码。
  • shr + unknown 按 JS 走 lshr（与历史强制 signed 不同），全量 sweep 无 fallout。
  • 一元 fneg 只处理确证 f32（fneg32）；操作数 domain 未知且无第二操作数佐证时保持 f64， 间接调用返回由 ftable 一致性播种覆盖。
  • sa run 在受限沙箱内 InvalidAddress 不可用，验证以 differential + oracle 为准。
  • 跟踪的 demos/c/*/main.c 镜像仍是旧后端产物，未随新后端重生成（有意为之，避免巨型 diff）。
