1.1 How to reproduce the gate

The pass criterion is a conjunction, not a single successful compile. For each demo, all four conditions must hold:

  1. sa build-c <demo>/main.sa -o out.c --project-root . exits 0.
  2. cc -Wall -Wextra -std=c99 -O2 out.c -o out exits 0 and prints no warnings.
  3. Running ./out exits 0.
  4. Its output matches the expected output of the interpreter/JS reference byte for byte.

A single demo can be checked with the commands above; the full 961-demo differential is a sweep, not a unit test. Two knobs are commonly needed while investigating a failure:

# tiny gas budget: forces the "out of gas" trap deterministically
cc -Wall -Wextra -std=c99 -DSA_GAS_LIMIT=1ULL out.c -o out_gas && ./out_gas
# [sa-trap] out of gas ; exit=1

# shrink linear memory to catch careless absolute addresses early
cc -Wall -Wextra -std=c99 -DSA_MEM_BYTES=65536UL out.c -o out_small

The numbers in section 1 are historical snapshot results from the sa-c branch built with Zig 0.17; they must be re-measured on a new toolchain rather than quoted as current behavior. A compile-time failure is not automatically a regression: the six recorded failures are all negative tests (import cycle, DuplicateDef, CapabilityMismatch, cross-directory rejection), where rejection is the correct outcome.

2. Representative Problems That Were Fixed

  • The indirect dispatch's empty table trapped unconditionally (uint64_t idx >= 0 always true); demo 466 regression.
  • 500+ dead helpers (suppressing warnings with NOLINT would be cheating): changed to on-demand emission + reachability trimming.
  • The u64 aliases rem/gt wrongly took the signed path (demos 388/389), i32 lshr was not narrowed (347), f32 chain domain pollution (452), indirect f32 return comparison (472).
  • The demos/c/219 mirror was missing the bin/ subtree (also collateral damage from the demos/**/bin/ ignore; completed with git add -f following the rosetta original).

3. Known Boundaries (Not Bugs, by Design)

  • An unknown extern is still a precise trap (sa_trap("extern …")), emitted on demand before the call, with no dead code.
  • shr + unknown follows JS to lshr (different from the historical forced signed), with no fallout in the full sweep.
  • Unary fneg handles only confirmed f32 (fneg32); when an operand's domain is unknown and there is no second operand to corroborate it, it stays f64, and indirect-call returns are covered by ftable-consistency seeding.
  • sa run is unusable with InvalidAddress inside a restricted sandbox; verification is based on differentials + the oracle.
  • The tracked demos/c/*/main.c mirrors are still products of the old backend and have not been regenerated with the new backend (deliberate, to avoid a giant diff).
