运行时：按需 helper、内存与 Gas

1. helper 按需发射（无死代码）

运行时约 130 个 helper（load/store/ALU/float/cvt/print 等）组成目录表， 发射器先把函数体写进侧 buffer，再用 名字 + "(" 文本扫描定使用集， 经依赖闭包补齐后只发射用到的那些（相对顺序保证被调者在前）。 效果：hello_world 从约 180 行降到 43 行。 无间接调用的程序整个跳过 sa_fn_t/sa_ftable/sa_call_indirect； 纯计算程序连 16MB 的 sa_mem 都不发射（sa_brk 只跟分配器走）。

配套裁剪：从未被跳转的 label 只保留 metering（消 -Wunused-label）； 从未被读的寄存器槽不声明（消 -Wunused-but-set-variable）； 从 main 不可达的用户函数整个跳过（无 main 的纯库单元全保留）； 未被调用的 extern 只有前向声明、没有 stub 定义。

2. 线性内存与检查

  • static uint8_t sa_mem[SA_MEM_BYTES]（默认 16MB，可用 -DSA_MEM_BYTES=… 覆盖），bump 分配器 sa_alloc（8 字节对齐）。
  • 所有 load/store/print 经 sa_checked_addr(addr, size) 做越界检查， 越界走 sa_trap("oob linear-memory access")；sa_trap 为 noreturn，错误输出到 stderr 并 exit(1)。

3. Gas 计量

static sa_u64 sa_gas = SA_GAS_LIMIT;   /* 默认 10000，可 -DSA_GAS_LIMIT=… 覆盖 */
#define SA_GAS_CHECK(n) do { \
  if (sa_gas < (sa_u64)(n)) sa_trap("out of gas"); \
  sa_gas -= (sa_u64)(n); } while (0)

每个函数入口与每个 SA_L_* 标签各扣 1 单位。 main 内有 (void)sa_gas; 保证符号被引用。 验证例：-DSA_GAS_LIMIT=1ULL 编译 hello（需 2 单位）运行报 [sa-trap] out of gas，exit=1。注意默认 1 万单位只够中小 demo， 循环上万次的真程序需要调大限额（见验证矩阵）。

注意生成的 C 只用确定性构造： 无 malloc（除 staged http 状态表，见 extern 章，也是固定大小静态数组）、 无平台相关头文件，同一输入在任何 -std=c99 编译器下输出一致。
