Runtime: On-Demand Helpers, Memory, and Gas

1. On-Demand Helper Emission (No Dead Code)

About 130 runtime helpers (load/store/ALU/float/cvt/print, etc.) form a catalog table; the emitter first writes the function bodies into a side buffer, then determines the used set with a text scan for name + "(", completes it through the dependency closure, and emits only those that are used (relative order guarantees callees come first). Effect: hello_world dropped from about 180 lines to 43 lines. Programs with no indirect calls skip sa_fn_t/sa_ftable/sa_call_indirect entirely; pure-computation programs do not even emit the 16MB sa_mem (sa_brk follows the allocator only).

Companion trimming: a label that is never jumped to keeps only metering (eliminating -Wunused-label); a register slot that is never read is not declared (eliminating -Wunused-but-set-variable); a user function unreachable from main is skipped entirely (pure library units with no main keep everything); an extern that is never called gets only a forward declaration, with no stub definition.

2. Linear Memory and Checks

  • static uint8_t sa_mem[SA_MEM_BYTES] (16MB by default, overridable with -DSA_MEM_BYTES=…), with the bump allocator sa_alloc (8-byte alignment).
  • All load/store/print operations go through sa_checked_addr(addr, size) for bounds checking; out-of-bounds access goes to sa_trap("oob linear-memory access"); sa_trap is noreturn, writes the error to stderr, and calls exit(1).

3. Gas Metering

static sa_u64 sa_gas = SA_GAS_LIMIT;   /* 默认 10000，可 -DSA_GAS_LIMIT=… 覆盖 */
#define SA_GAS_CHECK(n) do { \
  if (sa_gas < (sa_u64)(n)) sa_trap("out of gas"); \
  sa_gas -= (sa_u64)(n); } while (0)

Each function entry and each SA_L_* label deducts 1 unit. main contains (void)sa_gas; to guarantee the symbol is referenced. Verification example: compiling hello with -DSA_GAS_LIMIT=1ULL (it needs 2 units) and running it reports [sa-trap] out of gas, exit=1. Note that the default limit of 10,000 units is only enough for small and medium demos; a real program looping tens of thousands of times needs a larger limit (see the Verification Matrix and Known Boundaries page).

NoteThe generated C uses only deterministic constructs: no malloc (except the staged http state table — see the extern page — which is also a fixed-size static array), no platform-specific headers, and the same input produces identical output under any -std=c99 compiler.
