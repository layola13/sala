Booleans, Conditionals, and Loops

Booleans, Logic, if/elif/else, and the Ternary Form

psa spells the logic operators and/or/ not; SLA uses &&/||/ ! on bool values. The census marks psa and/or/not as supported (on pure booleans they lower to the SLA operators). Python's elif is SLA's else if, and blocks are braces, not indentation. Python's ternary x if c else y corresponds to SLA's if-expression: if c { x } else { y }, usable anywhere a value is expected.

psaSLA
def grade(score):
    if score >= 90:
        return 1
    elif score >= 60:
        return 2
    else:
        return 3

a = True
b = False
print(a and not b)            # True
print(a or b)                 # True
print(1 if 95 >= 60 else 0)  # 1
print(grade(95))              # 1
print(grade(70))              # 2
print(grade(10))              # 3
 
@import "sa_std/io/print.sai"
@import "sa_std/fmt.sai"

fn grade(score: i32) -> i32 {
    if score >= 90 {
        return 1;
    } else if score >= 60 {
        return 2;
    } else {
        return 3;
    }
}

fn main() -> i32 {
    let a = true;
    let b = false;
    println("{}", a && !b);
    println("{}", a || b);
    println("{}", if 95 >= 60 { 1 } else { 0 });
    println("{}", grade(95));
    println("{}", grade(70));
    println("{}", grade(10));
    return 0;
}

Verified output (SLA): true, true, 1, 1, 2, 3, exit code 0.

while, break, and continue

The loop forms correspond one to one. Census status: psa while with break/continue is supported; the while/else and for/else clauses are a recorded front-end gap in psa (loudly refused, low frequency). SLA has no loop-else either.

psaSLA
total = 0
i = 0
while i < 10:
    i = i + 1
    if i == 3:
        continue
    if i == 8:
        break
    total = total + i
print(total)  # 25
 
@import "sa_std/io/print.sai"
@import "sa_std/fmt.sai"

fn main() -> i32 {
    let sum = 0;
    let i = 0;
    while i < 10 {
        i = i + 1;
        if i == 3 { continue; };
        if i == 8 { break; };
        sum = sum + i;
    }
    println("{}", sum);
    return 0;
}

Verified output (SLA): 25, exit code 0.

for and range

psa's for i in range(...) is SLA's for i in a..b — the range is part of the loop syntax, with no separate range value. Census status for psa: partially supported — range with one or two arguments works in the for header (and in comprehensions/constructors), iterating a list variable or a string works, but a range object as a general value is still a gap. To walk a collection by index, both sides use the length: psa range(len(a)), SLA 0..len(a).

psaSLA
total = 0
for i in range(1, 5):
    total = total + i
print(total)  # 10

a = [10, 20, 30]
total = 0
for i in range(len(a)):
    total = total + a[i]
print(total)  # 60
 
@import "sa_std/io/print.sai"
@import "sa_std/fmt.sai"

fn main() -> i32 {
    let sum = 0;
    for i in 1..5 {
        sum = sum + i;
    }
    println("{}", sum);
    let a = [10, 20, 30];
    let total = 0;
    for i in 0..len(a) {
        total = total + a[i];
    }
    println("{}", total);
    return 0;
}

Verified output (SLA): 10, 60, exit code 0.

Key Points of This Page

  • and/or/not ↔ &&/||/!; elif ↔ else if; ternary ↔ if-expression.
  • while/break/continue correspond directly; loop-else exists on neither side (psa: recorded gap).
  • for i in range(a, b) ↔ for i in a..b; psa range as a standalone value is a gap (census: partial).
