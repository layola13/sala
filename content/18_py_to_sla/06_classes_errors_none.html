Classes, Errors, and None

Classes ↔ struct + impl

psa classes are supported by the census: single inheritance (flattened at compile time), methods, and __init__/__repr__/ __str__/__bool__; super() and multiple inheritance are loudly refused. SLA has no class form at all: the same shape is a struct for the fields plus an impl block for the methods, with a conventional new constructor function in place of __init__. Methods take self; a method that "changes" the value returns a new one (the plugin corpus's Counter demo works exactly this way).

psaSLA
class Pair:
    def __init__(self, a, b):
        self.a = a
        self.b = b

    def sum(self):
        return self.a + self.b

p = Pair(11, 22)
print(p.sum())          # 33
print(f"{p.a},{p.b}")   # 11,22
 
@import "sa_std/io/print.sai"
@import "sa_std/fmt.sai"

struct Pair {
    a: i32,
    b: i32,
}

impl Pair {
    fn new(a: i32, b: i32) -> Pair {
        return Pair { a: a, b: b };
    }

    fn sum(self) -> i32 {
        return self.a + self.b;
    }
}

fn main() -> i32 {
    let p = Pair::new(11, 22);
    println("{}", p.sum());
    println("{},{}", p.a, p.b);
    return 0;
}

Verified output (SLA): 33, 11,22, exit code 0.

Exceptions ↔ Result and panic

psa has real try/except/finally and raise (census: supported, with nine built-in exception classes; propagation crosses function boundaries). SLA has no try/catch form — the plugin corpus states this outright. The SLA split is by kind of failure:

  • Recoverable failures are values: the function returns Result<T, E>, and the caller inspects is_ok() / unwrap() (or matches on Ok/Err).
  • Unrecoverable faults are panic(code): the process prints PANIC: code=N and aborts; nothing catches it. The symmetry is closer than it first looks — psa's own runtime panics (out-of-bounds, bad conversions) are likewise not catchable by except, a divergence the census records explicitly.
psaSLA
def div(a, b):
    if b == 0:
        raise ValueError("division by zero")
    return a // b

try:
    print(div(7, 2))  # 3
    print(div(7, 0))
except ValueError:
    print("caught")   # caught
 
@import "sa_std/io/print.sai"
@import "sa_std/fmt.sai"

fn div(a: i32, b: i32) -> Result<int, int> {
    if b == 0 { return Err(0 - 1); };
    return Ok(a / b);
}

fn main() -> i32 {
    let v = 0;
    if div(7, 2).is_ok() { v = div(7, 2).unwrap(); };
    println("{}", v);
    println("{}", div(7, 0).is_ok());
    return 0;
}

Verified output (SLA): 3, false, exit code 0 — the second line is the Err case surfacing as data, where psa raises and catches.

The panic side, verified as its own program:

@import "sa_std/io/print.sai"
@import "sa_std/fmt.sai"

fn main() -> i32 {
    println("before");
    panic(77050);
    println("after");
    return 0;
}

Verified behaviour: prints before, then PANIC: code=77050, and exits with code 122; the after line never prints.

None ↔ Option

In psa, None is a real dynamic value: it can be bound, compared, printed, and stored in containers (census: supported). SLA has no null value at all. Absence is a type-level fact carried by Option<T> (import sa_std/core/option.sa), with Option::Some(v) / Option::None and a match to open it — the same Option that HashMap.get returned on the previous page.

psaSLA
def opt_or(opt, fallback):
    if opt is None:
        return fallback
    return opt + 1

print(opt_or(41, 0))    # 42
print(opt_or(None, 0))  # 0
 
@import "sa_std/core/option.sa"
@import "sa_std/io/print.sai"
@import "sa_std/fmt.sai"

fn opt_or(opt: Option<int>, fallback: int) -> int {
    let r = match opt {
        Some(v) => { v + 1 },
        None => { fallback },
    };
    return r;
}

fn main() -> i32 {
    let a: Option<int> = Option::Some(41);
    println("{}", opt_or(a, 0));
    let b: Option<int> = Option::None;
    println("{}", opt_or(b, 0));
    return 0;
}

Verified output (SLA): 42, 0, exit code 0.

Key Points of This Page

  • class ↔ struct + impl; __init__ ↔ a conventional new; psa classes are single-inheritance only.
  • No try/except in SLA: recoverable errors are Result values, unrecoverable faults are panic(code) — and psa runtime panics are equally uncatchable.
  • None is a value in psa; in SLA absence is Option<T>, opened by match.
